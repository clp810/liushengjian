# 产品约定

## 名称与方向

暂定名：留声间。

产品定位：收藏喜欢的音乐版本，拥有可个性化布置的听歌空间。长期方向类似私人数字收藏库；同一首歌的不同现场、翻唱和演绎有各自的信息、来源与记忆。

## 本版范围（v0.7 · 2026-10-18）

用户明确选择：暂未申请网易云开放平台凭证，先完成可用的本地版本与导出 / 手动导入流程。

完成标准：用户能通过界面导入 B站音频或本地文件、播放、修改信息、裁剪、保存收藏、导出并按指南上传网易云，不需要运行音频命令。

顺序：先实现可用 MVP，再完善视觉与交互；当前对话负责主线，后续按独立任务拆分。

第二版增加唱片墙、四种预设艺术封面、本地保存现场视频，以及保持片段进度的收听／观看切换。旧收藏继续使用，不搬动或覆盖原文件。DeepSeek 视觉原型仅作参考；正式界面使用真实收藏，不引入原型假数据与模拟播放。

第二版未接入 AI 原曲／原歌手识别，不提供在线歌手照片检索，不实现拖动唱片放入唱机的交互。更完整的听歌／观影沉浸体验留待后续迭代。

第三版聚焦用户明确要求的空间感与玻璃质感。使用本地 Folia 源码作为设计参考，自行实现 CSS 透视、玻璃控件、唱片聚焦、沉浸浏览和全屏体验；不引入 Folia 的播放器、账号或云音乐服务。

玻璃模糊只用于少量共享面板，唱片使用渐变边缘与阴影；只在指针移动时更新当前唱片，不运行持续动画循环。提供平面模式、触屏布局和系统减弱动效支持。

第三版还实现暂停状态的播放恢复与键盘操作。封面裁剪、更多配色、无限画布、自由摆放留待后续版本。

第四版聚焦听音室。用户选择先导入本地歌词并校准时间，不接入自动搜索。支持普通 LRC 逐句、增强 LRC `<分:秒>` 逐字标记；歌词与设置按收藏持久化，完整原音轨时间自动映射裁剪片段，切换收听／观看沿用同一播放时钟。整体偏移不能修正现场版本的段落差异。

歌词动效借鉴本地 Folia 0.7.18（`2fdf0386`）的时间与视觉分离：参考 `src/utils/lyrics/graphemeTiming.ts`、`src/components/visualizer/classic/Visualizer.tsx`、`glowWordTiming.ts` 的逐字时序、稳定布局、入场与光晕思路，在原生前端独立实现。没有引入 Folia 运行时依赖或服务。普通 LRC 不推算逐字演唱时间；三种情绪可手选，自动只用文字关键词，不分析音频。

现场视频的标题位于顶部，环境光用本地视频小画布低频采样。全屏视频占满视口，控件悬浮并延续闲置隐藏；默认保持完整构图，用户可选择裁切铺满。减少动态效果、后台与暂停状态都有降级；没有增加第二路视频／声音播放。

第五版让没有 LRC 文件的用户也能开始：搜索歌名／歌手 → 选择候选 → 核对演唱文字 → 本地 AI 逐句对齐 → 试听修正 → 明确保存。在线原曲歌词只提供文字，不直接当作现场时间轴。歌词来源包含网易云、QQ 和 LRCLIB；平台拒绝请求时如实提示，可换源或手动粘贴。

自动对齐使用 Whisper small / stable-ts，将已有文字与本地音轨对应，生成待检查的草稿。当前没有人声分离、不生成逐字时间、不做音频情绪识别。保留不确定或未定位的行并标出，禁止保存零时长、倒序、重叠和越界时间；不为缺失歌词编造均分时间。音频或原有歌词变更后，旧任务不能覆盖新版本。后台处理独立于播放，可取消；关闭窗口继续处理，关闭应用则中断，重启后可重新开始。

用户要求去除「已收起」：移除入口与操作，旧收起记录恢复到全部收藏，不删除音乐或历史输出。

第六版围绕极简听音室：进入即占满浏览器窗口，收听以当前句大字为主体，独立中文译文位于下方；背景从封面色调生成。导航、大标题、卡片与歌词技术状态不出现在播放主画面。播放、音量、进度、退出、模式与全屏作为浮层，闲置淡出；其余操作归入右下角设置。歌词管理也能从唱片详情独立打开，不改变当前播放的歌曲。观看现场保持单一播放器与裁剪时钟，整个视口用于视频和环境光。

第六版参考 Folia 的 `VisualizerShell.tsx`、`FloatingPlayerControls.tsx`、`VisualizerSubtitleOverlay.tsx` 与经典动态歌词布局，在原生前端独立实现；没有复制其 React 运行时或引入在线音乐播放服务。普通逐句数据使用版式与入场动效，逐字高亮只消费真实标记。可控制背景氛围、关闭环境光、遵循系统减弱动效。

中文优先读取同一候选的译文：先在该来源内按时间配对原文与译文，再按原文内容挂到现场句子，绝不把原曲时间当作现场时间。旧收藏可明确选择候选后只补译文，保留已校准时间及逐字信息；也可逐句编辑。没有匹配的译文留空，不按序号猜配。第六版要求用户明确保存；第七版改为自动补缺失译文，保留手动译文及已有时间轴。尚未接入自动 AI 翻译。

第七版将默认流程改成「进入收听 → 自动找歌词与中文 → 本地同步尝试 → 可靠性检查 → 自动保存或保留文本」。歌词窗口只显示歌曲、准备情况与继续听歌；复杂管理界面退入可选的「更多选项」。用户不需要选择来源、指定语言或修复模型的零时长／重叠问题。播放和准备独立，关闭窗口不取消，关闭应用会中断。可停止准备及关闭自动偏好。

选曲采用标题清理、原歌名与歌手相似度以及同名歧义检查，自动来源先用网易云；它不是通用大模型推理或音频指纹识曲。音频处理仍用 Whisper small，失败时再转录核对；只将实际观测的片段边界用于候选时间，不均分或填造未唱出的歌词。质量检查无法证明同步准确，失败时显示原文与中文供阅读，不让用户处理模型报错。已有歌词默认只补缺少的中文，用户主动重试才尝试替换时间；失败保留原记录。准备期间音轨／歌词版本变化则放弃旧结果，所有历史歌词文件保留。

环境氛围必须改变实际画面：暖光、夜色、林间分别控制背景与光层，开关环境光同时影响收听及视频。第七版修复旧样式匹配到主题按钮而非选中主题的问题，并验证画面差异。

用户提出后续通过摄像头捕捉手指／手部动作，作为不同于 Folia 的交互方向。本版不启用摄像头；后续可把手势作为播放控制的另一种输入，先验证误触、延迟与长时间使用体验。

## 技术决策

- 本地 Python 服务负责媒体处理与 SQLite 存储；浏览器仅提供界面。
- 监听本机回环地址，不发布网站、不创建云服务。
- 音轨获取复用 yt-dlp，音频处理复用 FFmpeg。
- 保存原始文件，每次裁剪重新从原文件生成；成功后才切换当前导出版本。
- 音乐条目、任务、封面与音频在磁盘上持久化。
- 优先使用明确错误和真实任务状态；不模拟网易云上传成功。
- 不读取其他应用的登录凭证。
- AI 依赖放在独立的 `alignment/` 环境，首次使用再安装；模型缓存在 `.cache/lyric-models/`，当前使用 CPU。音频不发往云端，搜索仅发送从收藏标题提取或用户填写的歌名／歌手。
- 固定歌词来源端点，不接受远程 URL 参数、不跟随重定向；候选令牌在内存短期保存。

## 后续候选

2. 网易官方上传接口的开发者接入与真实账号验证。
3. 音频封面嵌入、多个剪辑版本、批量导入、磁盘管理。
4. 自定义背景、场景编辑、唱片墙细化与更完整的听歌／观影体验。

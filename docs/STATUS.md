## 交付范围

留声间 **v0.4.0**：动态歌词与现场观看体验。保留 v0.3 空间玻璃唱片墙、聚焦详情和暂停恢复，以及原有本地音视频收藏、裁剪、封面与导出。网易云仍使用客户端手动上传。

- 听音室采用顶部歌名与版本信息、封面和歌词舞台、独立底部控制。歌词有前后句层次、当前句浮起及柔光；逐字 LRC 依据文件的实际时间标记填充高亮、浮动，普通 LRC 按整句聚焦。
- 导入本地 `.lrc`，支持 UTF-8、带 BOM 的 UTF-16、GB18030、重复句时间、同时间译文、空白间奏及文件 offset。原文件按新名字保留，解析内容存入当前收藏；失败导入不替换已保存歌词。
- 每份收藏可选完整原音轨／当前片段时间，设置提前或延后、选择一句并校准到当前声音；即时预览、取消恢复、保存后持久化。完整原音轨模式计入裁剪起点。歌词导入本身立即保存，取消按钮只撤销未保存的时间与动效调整。
- 舒缓、明亮、热烈三种文字情绪；自动模式以当前句少量中英文关键词选择，无关键词时舒缓。颜色、入场速度、浮动与光晕强度随选择变化，不分析音频。
- 现场标题移到视频上方，画面环境光来自 32×18 视频采样，最多每秒 4 次，可关闭。只使用原有视频播放器，没有额外声音源。
- 全屏视频元素占据整个视口，标题和控制悬浮显示、闲置淡出；默认完整显示，用户可选择裁切铺满。全屏不采样外围环境光。
- 文字更新最高约 30 次／秒；暂停、页面隐藏、离开听音室、减弱动态效果时停止连续更新。系统减弱动效保留歌词定位与静态高亮，关闭位移和视频采样光。
- 以本地 Folia 0.7.18 的歌词时序／视觉分离、稳定布局和光晕过渡为参考，在原生前端独立实现，未接入其在线服务或运行依赖。

## 实际限制与未验证部分

- 不自动搜索歌词，不支持 QRC、YRC、KRC 等专用格式。逐字文件目前支持 `<分:秒>` 标记；普通 LRC 不推算逐字演唱时间。同时间译文合并显示后使用整句高亮。
- 单文件最多 256 KB、1500 句、单句 500 字、总文本 5 万字；偏移限 ±600 秒。普通 LRC 无结束标记时显示到下一句，最后一句缺少结束时间时使用有限的默认时长。
- 整体偏移无法修复现场演绎与原曲间不同的段落、前奏／间奏长度，需要对应版本的歌词文件或在外部编辑时间轴。本版不是歌词逐句编辑器。
- 情绪判断只是文字关键词规则，不是 AI、音频情绪识别、节拍检测或音乐结构分析；可以手选覆盖，未验证识别准确率。
- 全屏默认保留原比例，比例不同时会有黑边；裁切铺满会损失画面边缘。浏览器支持和系统全屏行为仍有差异。
- 视觉与交互验证在本机 Chrome 完成；390 px 是模拟窄屏。Safari、手机实机、屏幕阅读器、大型收藏库及低性能硬件未全面验证，不宣称帧率或能耗指标。
- B站仍受网络、限流和平台规则影响；本次在线回归被页面读取超时阻断。只选择公开可用的最高 720p 以内视频，不读取 Cookie、不绕过登录或会员。
- 视频保留完整原片，按音频裁剪区间播放；边界受浏览器播放事件精度影响，听看切换可能短暂停顿，没有视频裁剪导出。
- 空间唱片墙是 CSS 透视，不支持自由漫游、无限画布或唱片投入唱机。AI 原曲／歌手识别、自定义封面裁剪、封面嵌入导出音频尚未实现。
- 浏览器播放记忆、环境光等显示偏好不进行多设备同步；歌词与其设置保存在收藏数据库。原文件与历史输出保留，暂无磁盘清理或后台任务取消功能。
- 本版未重复测试网易云客户端上传；处理不会提升原始音画质量。

# 开发状态 · 2026-10-15

## 交付范围

留声间 **v0.3.0**：以空间唱片墙和玻璃质感为主的体验升级。保留 v0.2 的本地音视频收藏、裁剪、预设封面、听看切换与音频导出。网易云仍使用客户端手动上传。

- 全宽空间唱片墙：轻微透视与错落、玻璃边缘、高光、厚度投影、指针经过时的轻微倾斜；平面模式可切换并记住选择。
- 共享导航、搜索栏和播放器使用半透明玻璃面板；背景使用柔光与细纹理。聚焦／播放时使用预设配色，图片封面可读取时采样本地图片色调。
- 点击封面打开玻璃聚焦详情，显示完整歌名、版本与笔记，可播放、心动、进入听音室或编辑／导出。封面角落单独保留快速播放；卡片「•••」管理菜单可收起／恢复、编辑、导出、重试。
- 沉浸浏览收起导航；唱片墙全屏仍能使用底部播放器。进入听音室后使用房间内控制面板，避免两套播放器重复。
- 听音室延续空间与玻璃风格；全屏播放闲置约 4 秒后隐藏面板，指针、触摸和键盘操作唤醒。键盘焦点在可操作控件时不隐藏。
- 恢复上次歌曲、进度和听看模式，但保持暂停，用户点击「继续播放」才开始。已收起或不可用的收藏不恢复；版本变化或上次已播完则从开头恢复。记忆仅保存在当前浏览器。
- 支持封面方向键导航、Enter 查看、Esc 关闭／退出沉浸；焦点不在编辑或操作控件时空格播放暂停，听音室左右方向键调整 5 秒。
- 窄屏提供简化空间效果；支持系统减弱动效。没有引入外部字体、远程视觉素材、账号服务或新前端依赖。

## 实际限制与未验证部分

- 空间陈列为 CSS 透视，不是可自由漫游的三维场景；不支持无限画布拖拽、自由摆放和唱片投入唱机。
- 封面裁剪、更多配色、AI 原曲／歌手识别、歌词同步和专用观影界面尚未实现。封面仍未嵌入导出音频。
- 图片色调是粗略采样，图片缺失或采样失败使用默认配色；没有逐封面人工调色。
- 视觉与交互验证在本机 Chrome 完成；390 px 是模拟窄屏。Safari、手机实机、屏幕阅读器、大型收藏库及低性能硬件未全面验证，不宣称帧率或能耗指标。
- 网页全屏可用性取决于浏览器；不支持时提示使用窗口全屏。玻璃模糊不可用时提供较实的背景色。
- 浏览器记忆不是多设备同步；清理网站数据会清除播放进度和显示偏好，磁盘收藏仍保留。
- B站下载仍受网络、限流和平台规则影响，仅选择公开可用的最高 720p 以内视频，不读取 Cookie、不绕过会员。单个成功样例不能代表全部来源。
- 视频保留完整原片，按音频裁剪区间播放；片段边界受浏览器播放事件精度影响。听看切换可能短暂停顿，没有视频裁剪导出。
- 原文件及历史输出保留，暂无磁盘清理或后台任务取消功能；处理不会提升原始音画质量。
- 本版未重复测试网易云上传；用户继续按客户端指南手动上传。Starlette/httpx 的既有弃用提示仍存在，测试通过。

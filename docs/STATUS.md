- 手机网易云端的同步、目标版本试听和普通歌单添加仍需用户确认。
- 封面目前用于本地界面，尚未嵌入导出音频。
- 不支持取消后台任务、批量链接、登录受限视频、B站短链接和完整背景场景编辑器。
- Python 测试依赖的 Starlette TestClient 对 httpx 发出弃用提示，当前测试正常通过。

## 启动

双击 `启动留声间.command`，或执行 `uv run --frozen --no-dev python run.py`。

数据在 `data/`，旧的样例输出仍保留在 `outputs/`；均不提交 Git。

## 实际限制与未验证部分

- AI 对齐是需人工试听的初稿。音乐伴奏、长前奏／间奏、和声、重复段落、缺句、改词和语种混合可能导致明显错误；小模型词概率只是检查提示，不是时间准确率。本版没有演唱数据集基准测试，不保证自动匹配准确。
- 输入文字需要与实际演唱顺序对应，重复副歌须重复填写；当前片段只应提供片段里的歌词。未定位句子可返回修改文字后重新生成，或手动修正时间。
- 网易云搜索与歌词读取、LRCLIB 搜索实测可用。QQ 实测接口返回拒绝（内部 code 2001），已有换源提示；QQ 真实歌词链路未验证成功，不能宣称可用。匿名接口可能改版或受限，不绕过账户、会员或验证要求。
- 首次使用联网安装独立 AI 依赖与约 461 MB 模型。当前电脑已缓存，CPU 推理仍有等待时间；换电脑后的首次完整下载与低性能机器耗时未测。推理不上传音频，无 API Key 或按次模型费用；联网搜索只发送用户填写的检索文字。
- stable-ts 上游仓库已归档，当前锁定 2.19.1，并锁定兼容 torch／torchaudio 2.8.0 与 openai-whisper 20250625。后续升级需重新验证。当前运行路径面向 macOS，Windows 未适配。
- LRC 文件导入不支持 QRC、YRC、KRC；上限 256 KB、1500 句、总文本 5 万字。同时间译文合并为整句；普通 LRC 不推算逐字时间。
- 自动情绪仍是少量文字关键词规则，不是音频情绪、节拍或音乐结构分析；可以手选覆盖。
- Chrome 桌面及模拟 390 px 窄屏已验收；Safari、手机实机、屏幕阅读器、大型收藏库和低性能硬件未全面验证。没有帧率、能耗保证。
- B站网络与平台规则可能变化；本次在线回归通过，不代表始终可用。只获取公开可用的最高 720p 以内视频，不读取 Cookie、不绕过登录或会员。
- 视频完整保留、按音频片段播放，无视频裁剪导出；默认全屏保留比例，裁切铺满会损失边缘。听看切换可能短暂停顿。
- 未实现 AI 原曲／歌手识别、在线歌手照片、封面裁剪／嵌入、自由漫游或唱片投入唱机。没有多设备同步、媒体磁盘清理或普通导入任务取消；本版只支持歌词对齐取消。
- 本版没有重复验证网易云客户端上传；编码不提升原始音画质量。

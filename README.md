# 留声间 · v0.7

收藏喜欢的版本，布置自己的听歌空间。

一个在本机运行的私人音乐收藏工具：B站链接 / 本地音视频 → 提取音轨 → 试听、整理信息和裁剪 → 保存收藏 → 导出 M4A / MP3 → 在网易云音乐客户端手动上传。

## 打开应用

在 macOS 访达中双击 **启动留声间.command**。应用会打开 <http://127.0.0.1:8765>。

首次启动需要联网安装项目依赖；后续使用本地文件无需联网。终端窗口用于运行本地服务，保持打开即可使用。再次双击会复用正在运行的留声间。

当前电脑已安装所需环境。若换电脑，需要：

- Python 3.12（`uv` 会管理项目 Python）
- [uv](https://docs.astral.sh/uv/getting-started/installation/)
- [FFmpeg / ffprobe](https://ffmpeg.org/download.html)，已使用 Homebrew 时可通过 `brew install ffmpeg` 安装

终端启动方式：

```sh
uv run --frozen --no-dev python run.py
```

如果默认端口被其他程序占用：

```sh
uv run --frozen --no-dev python run.py --port 8767
```

## 第七版新增：歌词自动准备

直接进入听音室收听，留声间会从收藏标题中提取歌名，在网易云寻找对应歌曲、原文与中文，并在本机尝试与演唱同步。无需先找 LRC、选择来源／语言或逐句修时间。点击唱片详情或听音室设置里的 **歌词**，查看简洁的准备状态；关闭窗口后继续处理，结果通过检查后自动保存。

- 先清理标题中的现场、画质等文字，结合歌名／歌手比较候选；无法确定的同名歌曲不强行选择。这一步是标题匹配规则，不是通用大模型或听歌识曲。
- 同步由本地 Whisper small / stable-ts 完成。第一次结果不可靠时自动尝试转录核对；对时长、重叠、内容覆盖及模型把握进行检查。未通过时保留原文和中文，在「歌词 → 查看歌词」阅读，不显示修复清单、不编造演唱时间。
- **已有时间轴优先保留**：默认只补缺少的中文，保留手动译文、逐字标记和偏移。需要重新同步时，在「歌词」点 **重新自动匹配**；失败时仍保留原有时间轴。旧歌词文件不覆盖。
- 同一首歌的结果会缓存，避免每次进入都重复分析。可主动重试，也可在「更多选项」关闭自动准备、修正识别的歌名，或使用导入文件／手动调整。
- 修复「暖光／夜色／林间」点击无变化：三种氛围现在分别呈现暖金、深蓝、林绿。环境光开关同时控制收听与现场的光照层，偏好刷新后保留。
- 中文来自歌词源，并非自动 AI 翻译；来源没有中文时不会凭空补译。音频仅在本机分析，联网发送歌名／歌手，不读取账号或 Cookie，不下载网易云音乐。

**实际效果边界**：本次用独立临时库测试截图中的日语现场，自动找到《丸ノ内サディスティック》与 28 句中文；本地模型仍未可靠完成这场演唱的同步，因此保留歌词文本。自动流程可用，真实现场的同步准确度仍需改进。

首次分析需联网准备独立组件及约 461 MB 模型，当前电脑已缓存。CPU 分析可能需要数分钟，不阻断播放；关闭应用会中断，重新打开可重试。自动同步目前分析不超过 15 分钟的完整原音轨，较长演出先保留文字。

## 听音室与手动选项

听音室占满浏览器窗口，原文以当前句大字呈现，中文在下方。播放／暂停、进度、音量、退出、收听／观看现场及全屏作为浮层，播放闲置约 3 秒后淡出；鼠标、触摸、键盘操作会唤回。观看现场沿用同一播放时钟，标题位于顶部；保留完整构图或裁切铺满可选。

普通 LRC／AI 逐句结果使用整句入场和版式变化，逐字亮起需要真实逐字标记。当前没有节拍／演唱情绪识别，没有摄像头手势功能。

需要自己微调时，进入 **歌词 → 更多选项 → 导入文件／手动调整**：

- 导入 LRC、调整整体偏移、试听原音轨、逐句编辑中文。
- 「找歌词／补充中文」保留旧版手动工作流：选择候选与演唱文字 → 本地对齐 → 试听校准 → 确认保存。只用于自愿深入调整，不是自动模式的必经步骤。
- 手动来源保留网易云、QQ 音乐和 LRCLIB。网易云本版实测可用；LRCLIB 搜索曾通过验证，QQ 曾拒绝查询，不保证各平台一直可用。
- 手动分析最多 15 分钟、500 句、每句 500 字、总文本 16000 字；可选原音轨或裁剪片段。现场伴奏、重复段落及改词可能造成错误，手动草稿仍需试听确认。

## 第四版新增：歌词与现场

- 保留逐句与逐字 LRC；第六版改为整屏当前句舞台，逐字 LRC 根据真实时间标记亮起。
- 在「歌词 → 更多选项 → 导入文件／手动调整」导入 `.lrc`；支持 UTF-8、带 BOM 的 UTF-16 和 GB18030 文本。支持重复句时间、同时间译文、空白间奏及文件内 `[offset:毫秒]`。
- 每份收藏保存歌词、偏移、时间基准和文字情绪。选择「完整原音轨」时自动计入裁剪起点；片段专用歌词可以选择「当前收藏片段」。
- 可提前／延后 0.25 秒、直接输入 ±600 秒偏移，或选一句点「这句现在开始」。调整即时预览，点击保存才持久化；取消恢复之前设置。歌词导入本身会立即保存，更换会保留旧歌词文件。
- 舒缓、明亮、热烈三种动效。自动模式仅根据当前歌词的少量中英文关键词切换，不是 AI 或音频情绪识别；没有对应关键词时使用舒缓。
- 现场标题位于顶部悬浮层；环境光来自低分辨率视频采样，可关闭。全屏后视频元素占满整个视口，信息与控制悬浮在画面上，闲置淡出；支持完整显示和裁切铺满两种构图。
- 支持系统减弱动效；切到其他页面、后台或暂停后停止连续逐帧更新。视频环境光最多每秒采样 4 次，第六版也用于全屏视频周围的留白。

**怎么体验**：点击唱片封面 → 歌词 → 更多选项 → 导入文件／手动调整 → 导入 LRC → 用原音轨试听校准 → 保存设置。观看现场 → 全屏 → 右下角设置中选择「画面：裁切铺满」（会裁去画面边缘）。

普通 LRC 示例为 `[00:12.50]这一句歌词`；逐字示例为 `[00:12]<00:12>这一<00:13>句歌词<00:15>`，最后一个空标记可指定本句结束。歌词时间对应当前收藏的具体演绎版本；原曲与现场有不同段落、间奏时，仅整体偏移无法修正所有句子。

## 第三版新增

- 空间唱片墙：唱片轻微透视、玻璃边缘、高光和厚度投影；鼠标经过时轻微倾斜。窄屏与系统减弱动效模式会简化效果。
- 悬浮玻璃导航、搜索工具栏与底部播放器；点击「沉浸浏览」收起导航，点击「全屏」铺满屏幕，可随时退出。
- 点击封面打开聚焦详情，查看版本与笔记、播放、心动或进入听音室。快速播放在封面右下角；编辑、导出移至卡片右下角「•••」。
- 「空间陈列／平面陈列」可切换，选择保存在这个浏览器。封面可用时提取本地图像的平均色调用于氛围光，预设封面使用对应配色。
- 第六版听音室独立为整屏舞台，普通窗口和全屏播放都支持闲置隐藏控制。
- 重新打开时恢复上次歌曲、进度及收听／观看模式，保持暂停；点击「继续播放」后开始。不可播放的收藏不恢复，音频版本发生变化时从开头恢复。
- 键盘操作：聚焦唱片封面后用方向键移动，Enter 查看；Esc 关闭详情／退出沉浸。焦点不在输入框或按钮时，空格播放暂停；听音室左右方向键调整 5 秒。

**体验方式**：点击一张封面 → 查看详情 → 进入听音室；唱片墙右上角可切换空间／平面、沉浸与全屏。空间陈列使用轻量 CSS 透视，尚不支持无限画布拖拽和自由摆放。

## 第二版功能

- 暗色唱片墙：突出封面、选中状态和收藏信息，支持搜索、排序、心动及进入听音室。
- 添加音乐时可选择原始／默认封面或「声纹、剪影、字间、暮色」四种预设艺术风格；编辑时可切换，上传的图片和原始封面分别保留。
- 添加时选择「音频＋现场视频」，从支持的 B站链接或本地视频准备可在本机观看的 MP4。已有音频收藏可在听音室从原来源补充视频。
- 听音室可切换「收听／观看现场」，保留片段内进度及播放／暂停状态；视频只播放当前收藏所选的裁剪区间。
- 听音室全屏内可播放、暂停、拖动进度、切歌、调节音量和单曲循环。

**体验方式**：添加音乐 → 选择保存内容与封面 → 完成后点击「进入听音室」→ 收听或观看现场。已有的纯音频文件无法凭空生成现场画面。

## 保留功能

- B站单个 BV 视频链接 / BV 号导入，保留来源；支持链接中的 `?p=2` 分 P 参数。
- 本地 MP3、M4A、AAC、FLAC、WAV、OGG、Opus、MP4、MOV、MKV、WebM 导入；实际可用性取决于文件内编码。
- 原音轨保存、M4A 和 MP3 导出；支持最多 4 小时、单文件 512 MB 的本地音视频。
- 音频播放、拖动进度、上一首 / 下一首、单曲循环、音量控制。
- 歌名、演唱者、版本、专辑 / 系列、收藏笔记编辑。
- 从原音轨试听片段、设置起止时间、重新裁剪；不会反复使用上次裁剪结果。
- 本地收藏库、搜索、排序、心动收藏。
- 导入任务记录、错误提示、失败重试；重启后识别未完成任务。
- B站封面可获取时自动保存；支持更换本地 JPG / PNG / WebP 封面。
- 听音室与暖光 / 夜色 / 林间三种氛围，主题和音量保存在浏览器。
- 网易云客户端导入指南、文件下载、在访达中显示导出文件。

如果项目仍保留首个真实样例的 `.cache/BV1CFG66UELP.source.m4a`，初次启动会将其复制到收藏库。没有该文件时显示空收藏库，不会自动下载演示歌曲。

## 导入网易云音乐

1. 在歌曲卡片点击「导出」。
2. 下载 M4A / MP3，或点击「在访达中显示 MP3 文件」。
3. 在网易云音乐客户端打开「我的音乐网盘」，上传刚导出的文件。
4. 在手机同一账号下确认同步并试听目标版本。

**本版本采用手动上传流程，不包含网易云开发者凭证配置、自动云盘上传、自动加入歌单。** 留声间不读取网易云账号、浏览器 Cookie 或其他应用的凭证。

## 关于音质与封面

- 原始 AAC 音轨未裁剪时，M4A 保留原音轨，不再有损转码。
- 裁剪、非 AAC 源转为 M4A，以及 MP3 导出都需要编码。MP3 使用 192 kb/s；这不会提升原始音质。
- 原文件始终保留。编辑生成新版本，之前导出的旧文件不会被覆盖；MVP 暂未提供磁盘清理功能。
- 预设封面由本地样式绘制，不调用 AI；原始封面是来源视频封面，不等于原曲专辑封面。歌词支持标题匹配；尚未实现音频识曲及歌手照片搜索。
- 封面目前用于本地收藏与听音室，暂不写入导出的音频文件。音频文件会写入歌名、演唱者、专辑和备注 / 来源标签。
- 歌曲信息可以手动修正。程序不会把 B站上传者直接当作演唱者。

## 数据与备份

默认全部保存在项目的 `data/` 文件夹中：

```text
data/
  library.sqlite3        收藏与任务记录
  tracks/<id>/
    source.<ext>         原文件
    live-<id>.mp4       可选的完整现场视频
    video-source-*/      为旧收藏补充视频时保存的来源
    preview.m4a          可在浏览器试听的完整音轨
    cover*.jpg           封面（如果有）
    lyrics-*.lrc         导入的歌词原文件（解析内容与设置在数据库）
    lyrics-*.json        自动准备的歌词／AI 时间轴／编辑后的译文（历史版本保留）
    lyric-tasks/<id>/    对齐草稿、分析音轨与诊断记录
    renders/<revision>/  每次生成的 M4A / MP3
```

退出应用后备份整个 `data/` 文件夹。将备份放回即可恢复；路径存储为相对路径，可以移动项目。音频和运行数据已列入 `.gitignore`，不会随代码提交。

可通过 `LIUSHENGJIAN_DATA` 环境变量指定其他本地数据目录。应用只监听 `127.0.0.1`，不对局域网或公网开放。

## 已知边界

- 在线候选不保证含中文；没有自动 AI 翻译。自动准备可补已有收藏缺少的译文，无法对应的行留空，可选手工填写。

- 自动选曲依据标题信息，无法覆盖所有别名、翻唱与混合标题；对齐检查不是准确率保证，复杂现场可能只保留歌词文本。LRC 文件导入仍可用，不支持 QRC、YRC、KRC 等专用格式；文件导入限 256 KB、1500 句、单句 500 字、总文本 5 万字。
- 普通 LRC 无结束标记时显示到下一句；最后一句缺少结束时间时采用有限显示时长。同时间译文合并显示，不保留逐字高亮；逐字时间必须单调且不超过下一句。
- 情绪规则是可覆盖的文字提示；不理解反讽、复杂语境或音乐结构。动态效果不代表节拍、响度或真实演唱情绪。

- B站现场视频选择公开可用的最高 720p 以内版本，不代表每个来源都有 720p；不绕过登录或会员限制。
- 视频保留完整原片，播放时限制到音频裁剪区间。已有音频补视频时只校验时长差异，无法检测平台换源后同等时长的内容变化。
- 本地可播视频另存为 H.264 / AAC MP4；兼容编码尽量复制，其余需要转码。会增加处理时间与磁盘占用，不提升原始画质或音质。
- 视频切换需要加载和定位，可能短暂停顿；片段结束依赖浏览器播放事件，并非逐帧剪辑。暂不提供裁剪视频导出。
- 本机 Chrome 已验证；Safari、移动端实机及多种特殊编码尚未全面验证。

- B站提取使用 [yt-dlp](https://github.com/yt-dlp/yt-dlp)，平台改版、限流、登录要求可能导致导入失败。MVP 不读取或导入浏览器登录状态；失败时可导入本地文件。
- 当前不支持 B站短链接、合集批量导入、视频搜索、远程多设备同步。
- 同一个 B站视频链接会被去重；多个自定义剪辑的独立版本管理留待后续扩展。
- 封面展示、本地播放和收藏数据已实现；完整场景编辑器、账号系统和软件安装包不在本版范围。
- 仅处理你有权下载、处理和保存的音视频内容。

技术栈：Python / FastAPI / SQLite / yt-dlp / FFmpeg；前端为原生 HTML、CSS、JavaScript，无需 Node 构建。
